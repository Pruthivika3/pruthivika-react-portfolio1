# Pruthivika M R — React Portfolio

A responsive personal portfolio built with **React + Vite**, adapted from the Hudson visual template.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The deployable files are generated in `dist/`.

## Deployment

- GitHub: push this project to `Pruthivika3.github.io` (or a dedicated portfolio repository).
- Vercel: import the GitHub repository. Framework preset: Vite. Build command: `npm run build`. Output directory: `dist`.
- AWS S3: upload the contents of `dist/` to an S3 bucket. For S3 static website hosting, enable static website hosting and configure the index document as `index.html`.
